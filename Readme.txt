# Web Responsive

Este proyecto forma parte de mi proceso de aprendizaje y práctica en desarrollo web. En él he trabajado la creación de una página completamente responsive, cuidando tanto la estructura como la adaptación a diferentes tamaños de pantalla.

Además de la maquetación con HTML y CSS, he incorporado JavaScript para añadir pequeñas funcionalidades e interacción a la página.

## Tecnologías utilizadas

* HTML5
* CSS3
* JavaScript

## Qué he trabajado

* Diseño responsive para móvil, tablet y escritorio.
* Organización del código en diferentes archivos CSS.
* Uso de Flexbox para la distribución de los elementos.
* Estructura semántica y navegación sencilla.
* Interacciones básicas con JavaScript.

## Objetivo

Seguir mejorando mis conocimientos en desarrollo frontend mediante proyectos reales, poniendo en práctica nuevas técnicas y mejorando la calidad de mi código con cada proyecto.
